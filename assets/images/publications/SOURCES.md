## Training High-Level Schedulers with Execution-Feedback Reinforcement Learning for Long-Horizon GUI Automation

Local image: `ces.webp` (1234 × 539).

- Source: https://openaccess.thecvf.com/content/CVPR2026/papers/Deng_Training_High-Level_Schedulers_with_Execution-Feedback_Reinforcement_Learning_for_Long-Horizon_GUI_CVPR_2026_paper.pdf
- Figure: Figure 3, page 4
- Description: Figure 3. The CES multi-agent loop framework. CES executes complex long-horizon tasks through the collaboration of three specialized agents. The Coordinator, as the task scheduling and decision-making core, combines the user’s high-level instruction and the current task state (provided by the State Tracker) to decompose the task into a clear atomic instruction. The Executor, acting as the tool, precisely executes this atomic instruction and interacts with the GUI environment. Finally, the State Tracker, as the memory, observes the Executor’s output and updates it into a high-semantic task state summary, which is then fed back to the Coordinator for the next step of decision- making.
